# Installation

## Stable release

To install OptiText, run this command in your terminal:

```sh
uv add OptiText
```

Or if you prefer to use `pip`:

```sh
pip install OptiText
```

## From source

The source files for OptiText can be downloaded from the [Github repo](https://github.com/iuryrdns/OptiText).

You can either clone the public repository:

```sh
git clone https://github.com/iuryrdns/OptiText
```

Or download the [tarball](https://github.com/iuryrdns/OptiText/tarball/main):

```sh
curl -OJL https://github.com/iuryrdns/OptiText/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd OptiText
uv sync
```
